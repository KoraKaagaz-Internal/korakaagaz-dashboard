Invoice Generator

Live: invoice-generator-flax-pi.vercel.app · Supabase project invoice-generator (ref komdaeylldwknhwcjevv, Mumbai) · Vercel project invoice-generator

A private web app for Kora Kaagaz that creates invoices matching the brand template, exports them as PDFs, and keeps a searchable history with paid/unpaid tracking and saved clients.

  • Stack: Next.js 15.5.28 (App Router, TypeScript, Tailwind 4) on Vercel · Supabase (Postgres, magic-link auth, Storage) · Puppeteer + @sparticuz/chromium for PDFs.
  • Users: one owner. Sign-in is limited to the emails in ALLOWED_EMAILS, and every table uses row-level security keyed on auth.uid().
  • Template fidelity: the invoice is a fixed 852 × 1278 px page (2:3). The browser preview, the print page and the PDF all render the same React component, so they match exactly.
Open item: the fonts (DM Serif Display and Inter) are stand-ins until the Figma font names are confirmed. The side image is the real artwork (public/brand/fabric-panel.jpg, corner brackets baked in). Diff against the reference screenshot: 3.2% of pixels in the content area (anti-aliasing, the added "Invoice no." field and dummy sample data). The photo column differs only because the new artwork replaces the screenshot crop.

    Sensitive data

    Bank account, PAN and client details live only in your Supabase project. Keys sit in .env.local (git-ignored) and Vercel environment variables. Nothing is sent to third parties.

    Totals

    subtotal = Σ qty × unit price → discount (flat or %, capped at subtotal) → GST on the discounted amount (CGST+SGST split evenly, or IGST) → total. Amounts are rounded to paise and shown with Indian grouping (1,50,000). Computed in src/lib/money.ts, used by both the preview and the server, and stored on the invoice.

    Limits and cost

    • Supabase free tier: 500 MB database and 1 GB storage. One PDF is about 0.6 MB with the placeholder images, so roughly 1,500 PDFs. Free projects pause after a week with no activity.
    • Vercel Hobby: free. The PDF function is allowed up to 60 s; a cold start of Chromium takes about 3–6 s.
    • Pagination: pages are planned ahead from estimated row heights (src/lib/paginate.ts). Very long single descriptions (more than about a page) get clipped. Split them into several items.
    • Client name: one line. Names over 16 characters drop to 28px; very long names get an ellipsis.

    Run and deploy

    One-time setup (already done for production)

    Done on 2026-10-27 with the Supabase CLI and Management API: project created, migrations pushed, owner user created, sign-ups disabled, Site URL and redirect URLs set. Vercel env vars set, and the anon key is stored as public config (RLS protects the data).

    1. Create a Supabase project → SQL editor → run supabase/migrations/0001_init.sql
2. Auth → Providers → Email: enabled.  Auth → Settings: disable "Allow new users to sign up"
   after your first sign-in (or create your user under Auth → Users first).
3. Auth → URL configuration: Site URL = your Vercel URL; add http://localhost:3000/auth/callback
   and https://<your-app>/auth/callback to Redirect URLs.
4. cp .env.example .env.local and fill in the four values.

    vercel link
vercel env add NEXT_PUBLIC_SUPABASE_URL

    Glossary

    RLS (row-level security)
    Postgres rules that make every query return only your rows, even if a bug sends the wrong query.
    Snapshot
    A copy of the client and payment details stored on the invoice, so history doesn't change when you edit a client or Settings.
    Magic link
    Passwordless sign-in: Supabase emails you a one-time link.
    CGST / SGST / IGST
    Indian GST. Same-state sales split the rate into Central and State halves; inter-state sales use Integrated GST at the full rate.
    Server action
    A Next.js function that runs on the server and is called straight from a form or button (src/app/actions.ts).
    Print page
    /print/[id]: the invoice with no app chrome, which headless Chromium turns into the PDF.
    Visual diff
    A pixel-by-pixel comparison of the rendered template against the design image (pixelmatch).
